# Docs

A small set of pages: what the code does, the experiments behind each claim in the top-level
README, and the ledger of what was withdrawn.

| folder | holds |
|---|---|
| [reference/](reference/) | what the code does today, one page per stage: [calibration](reference/calibration.md), [detection and tracking](reference/detection-tracking.md), [identity](reference/identity.md), [measurement](reference/measurement.md), [ball](reference/ball.md) |
| [experiments/](experiments/) | one dated run each: question, pre-registered rule, result, verdict (`nNN-slug.md`) |
| [ledgers/](ledgers/) | [claims](ledgers/ledger-claims.md) (including withdrawn and refuted ones, with what refuted them) and [assumptions](ledgers/assumptions.md) (each tagged VERIFIED or UNVERIFIED) |
| [guides/](guides/) | [glossary](guides/glossary.md) and [how pitch mapping works](guides/pitch-mapping-explained.md) |
| [img/](img/) | images the pages embed |

[INDEX.md](INDEX.md) lists every page with its date and sections. It is generated by
`.venv/bin/python model/validation/index.py`; do not edit it by hand.
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) lists software dependencies and their licences.

Pages mention other write-ups as "(not published)" or internal notes as "(internal note)". Those
exist in the author's working repository and were left out of this one to keep it small.

## Numbers

Every number carries a tag: `@M` measured, with the command that re-measures it; `@C` cited;
`@D` derived, with the arithmetic. The convention is in `model/validation/verify_claims.py`.
Do not quote a number from a page without its tag.

    .venv/bin/python model/validation/verify_claims.py        # re-runs the measured tags (needs $ST2_DIR)
    .venv/bin/python model/validation/lint_truth.py           # mechanical checks
    .venv/bin/python model/validation/doclinks.py --check     # dead docs paths and anchors
